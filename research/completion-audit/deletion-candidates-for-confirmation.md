## Safe deletion procedure after confirmation

1. Select the surviving canonical card and move over any unique question,
   context, distinction, connection, or source link.
2. Redirect thought-network references and favorites/import migration if an ID
   has shipped publicly.
3. Move the retired illustration into `research/retired-illustrations/` before
   any permanent deletion.
4. Deliberately update the library count and curation rule; do not add filler
   merely to satisfy an old fixed-count test.
5. Re-run source, interpretation, illustration, localization, build, and
   extension-package checks.
