# 品牌规范：未定稿 / NOTHING FINAL

## 品牌与产品名称

- 简体中文品牌：**未定稿**
- 繁体中文品牌：**未定稿**
- 英文品牌：**NOTHING FINAL**
- 简体中文商店名：**未定稿｜思想与知识新标签页**
- 繁体中文商店名：**未定稿｜思想與知識新分頁**
- 英文商店名：**NOTHING FINAL — Ideas on Every New Tab**
- 中文口号：**一页，一种思想。**
- 英文口号：**One page, one idea.**
- 中文传播句：**不是金句，是思想的来路与去处。**
- 英文传播句：**Not just a quote, but the path an idea has traveled.**

中文界面和中文物料使用「未定稿」，英文界面和英文物料使用 `NOTHING FINAL`。仅在许可证、双语品牌说明或需要跨语言识别时并列写作「未定稿 / NOTHING FINAL」。英文品牌保持全大写，中文品牌不添加书名号作为标志的一部分。

## 品牌含义

“未定稿”不是未完成的借口，而是一种阅读立场：知识可以被核查，解释可以被修正，观点也可以在新的证据与对话中继续展开。`NOTHING FINAL` 保留同样的开放性——一张卡片不是结论的终点，而是回到来源、理解语境并形成自己判断的入口。

这个名字可以自然覆盖哲学、中国哲学、毛选、科学、经济、心理、印度哲学和用户自己的知识集，不再把产品限制为单一传统或“名人名言”工具。

## 产品定位

「未定稿」是一款思想与知识新标签页工具。每次打开新页，用户会遇见一张卡；点开后可以继续阅读原文节选或命题整理、来源、解读、相关观点与留给当下的问题。

传播时按以下顺序表达：

1. **识别产品**：未定稿｜思想与知识新标签页
2. **建立记忆**：一页，一种思想。
3. **解释差异**：不是金句，是思想的来路与去处。
4. **说明范围**：阅读七个预设内容库，也可以导入自己的知识集。

## 表述边界

不要使用“最全”“权威收录全部思想”“每一句都是作者原话”等无法持续证明的表述。更可靠的表达是：

- “每开一页，遇见一种思想”
- “从一张卡，继续读到出处与语境”
- “让自己的知识也出现在新标签页”
- “持续核查、持续扩充的策展知识库”

“原文节选”“命题整理”“待核摘录”必须使用产品中的真实状态，不以引号、作者署名或营销文案模糊三者边界。

## 视觉提示

品牌符号是一枚留有缺口的圆。圆表示人总想获得完整答案，缺口表示答案仍可被追问；一枚暖色小点带来方向和生命感。标志应保持简洁，在 16–128 像素范围内仍能识别，不在图标内部堆叠字母或口号。

视觉主题可以变化，品牌文字本身应保持稳定。动效用于建立呼吸感与空间关系，不让正文、作者和作品信息漂移。

## 单一事实来源与兼容项

品牌名、版本、口号、传播句和多语言描述统一维护在项目根目录的 `brand.json`。扩展清单、网页元信息、分享标题与商店素材应从这里生成或读取，避免再次遗漏改名。

为保持已发布扩展与仓库兼容，以下技术标识暂不随品牌改名：

- GitHub 仓库地址与 `agora-philosophy` slug；
- `release/agora-philosophy-*.zip` 等既有产物文件名；
- `agora-*` 本地存储键及其他迁移所需的内部标识；
- 内容来源状态、翻译性质等既有 schema 枚举值。

这些标识不是面向用户的品牌文案，不应出现在新宣传素材的主视觉中。名称正式扩大使用前，仍应完成适用地区的商标、域名和应用商店重名检索；本文不构成法律意见。
