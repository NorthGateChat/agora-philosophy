# 未定稿｜思想与知识新标签页 隐私说明

**English product name: NOTHING FINAL**

**生效日期：2026-08-27**

**维护者：NorthGateChat**

「未定稿｜思想与知识新标签页」（英文名 `NOTHING FINAL`，以下简称“未定稿”）希望用尽可能少的数据完成一件事：在新标签页呈现预设内容或用户自己的知识卡，并让用户在本地阅读、收藏、屏蔽、回顾与分享。当前版本无需账号、无需任何 Chrome 权限，也不包含广告或用户行为追踪。

## 我们不收集什么

当前版本不收集、上传、出售或共享任何个人数据，包括但不限于：

- 姓名、邮箱、账号、设备标识符或其他身份信息；
- 浏览历史、访问网址、搜索词、网页内容或下载记录；
- 精确或大致位置；
- 键盘输入、剪贴板历史或其他应用中的内容；
- 用户导入的知识集、卡片、来源说明或备份文件；
- 使用频率、点击行为、崩溃遥测或广告画像。

未定稿不使用第三方分析 SDK、广告 SDK、追踪像素或远程日志服务，也不为用户建立跨网站或跨设备画像。

## 浏览器权限

当前版本申请的 Chrome 权限数量为 **0**。它只通过扩展清单中的新标签页覆盖能力显示自己的页面，不读取其他标签页、网站或浏览器历史。

如果未来某个功能确实需要新增权限、账号或网络服务，我们会先更新本隐私说明和 Chrome Web Store 的数据披露，并在产品中解释用途；不会为尚未实现的功能预先申请权限。

## 仅保存在本机的数据

为了记住用户的选择，未定稿在扩展自己的浏览器存储空间中保存：

- 主语言、中文是否同时显示英文、视觉主题与分享图比例；
- 当前内容库，以及经济、心理等内容库中的子集选择；
- 收藏、屏蔽、近期出现记录与新手引导状态；
- 用户创建或导入的知识集、卡片、来源说明和编辑内容；
- 用户主动创建的本地备份或最近一次可撤销操作所需的数据。

普通偏好主要保存在扩展页面自己的 `localStorage`；自定义知识优先保存在浏览器本地的 IndexedDB，并保留兼容性本地存储方案。这些内容不会由未定稿上传到服务器，也不会由未定稿在设备间同步。当前没有服务器端账号系统，因此发布者无法查看、恢复或替用户迁移这些本地内容。

用户可以在知识管理界面删除自己的知识集，也可以通过以下方式清除全部本地数据：

1. 在 Chrome 中移除“未定稿”扩展；或
2. 在 Chrome 的扩展/站点数据设置中清除该扩展的存储数据。

删除本地数据后，偏好、知识集、收藏、屏蔽和阅读记录无法由发布者恢复。

## 用户主动触发的文件、剪贴板与分享功能

导入、导出和备份操作只在用户明确选择文件或保存位置后进行。文件内容在本地解析或生成，不会被发送到项目服务器。用户把提示词复制到其他 AI 产品、把材料交给其他服务处理，或把导出的文件上传到第三方时，后续数据处理受对应服务自身的隐私规则约束。

分享图片在浏览器本地生成。打开分享弹窗、预览不同尺寸或保存图片不会上传图片。只有当用户主动点击系统分享时，浏览器或操作系统才会显示分享面板；在环境支持的情况下，本地生成的图片、当前卡片文字和商店链接会交给用户选择的目标应用。

用户主动选择“复制文本”“推荐给好友”或复制导入提示词时，未定稿只把相应内容写入剪贴板。未定稿不会读取剪贴板或剪贴板历史，也不会接收用户的第三方平台账号、联系人、最终发布内容或分享结果。

## 第三方共享、出售与广告

未定稿不向第三方出售或共享用户数据，不使用用户数据投放个性化广告，也不进行信用评估、保险评估或其他敏感用途。由于当前版本不收集用户数据，也不存在由未定稿服务器保存的数据留存期限。

## 儿童隐私

未定稿不是面向儿童定向收集数据的服务。当前版本不收集任何用户的个人数据；如果产品未来增加账号、投稿、联网同步或面向儿童的功能，会在上线前重新评估适用的儿童隐私义务。

## 隐私说明变更

如果产品功能或数据处理方式发生变化，我们会更新本页、生效日期以及 Chrome Web Store 中的隐私披露。重大变化会在合理可见的位置说明，不会用更新隐私说明来追认此前未披露的数据收集。
