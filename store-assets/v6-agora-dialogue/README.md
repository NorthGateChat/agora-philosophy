# AGORA · Chrome Web Store 素材 V6

这套素材使用统一的“开口 O”标志：未闭合的圆代表仍可继续追问的思想，右上角的橙色圆点代表一个新观点进入 Agora。圆点与开口保持静态关系，不表达加载进度。

## 可直接上传

- `store-icon-128.png` — 128 × 128；图形位于 96 × 96 安全区，外侧透明。
- `small-promo-440x280.png` — 440 × 280；24 位 PNG，无 Alpha。
- `marquee-1400x560.png` — 1400 × 560；24 位 PNG，无 Alpha。

## 可编辑源文件

`source/` 内保留图标、字标和两张宣传图的 SVG。字标与图标中的 O 使用同一个几何母版。
