# AGORA · Chrome Web Store assets v3

这是一套可直接上传的 Chrome Web Store 图片资源。新版以“开放方庭 + 思想节点”为品牌母题，截图以真实产品界面为主体。

## 上传目录

- `upload/global/store-icon-128.png`：商店图标（128 × 128，透明边距）
- `upload/zh-CN`：简体中文截图 5 张
- `upload/zh-TW`：繁体中文截图 5 张
- `upload/en`：英文截图 5 张
- `upload/global`：全球通用英文截图、440 × 280 小型宣传图、1400 × 560 顶部宣传图

所有截图和宣传图均为 24 位 RGB PNG、无透明通道。商店图标保留透明画布，96 × 96 主图形位于 128 × 128 画布中央。

## 建议上传方式

1. 简体、繁体、英文截图分别放入对应语言的“以当地语言显示的资源”。
2. 全球通用截图使用 `upload/global/screenshot-*`。若商店后台不需要重复素材，可只保留英文全局组。
3. 小型宣传图和顶部宣传图使用 `upload/global` 中同名文件。
4. 视频不是必填项；没有成片时留空，比上传低质量录屏更合适。
