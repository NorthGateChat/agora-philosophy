## 推荐顺序

1. 每开一页，换一种眼光。
2. 思想集、语言与手稿样式，都由你决定。
3. 不止一句话，还要说清它从哪里来。
4. 顺着节点，把不同的回答放在一起读。
5. 把读过的思想，留存，也分享给别人。
