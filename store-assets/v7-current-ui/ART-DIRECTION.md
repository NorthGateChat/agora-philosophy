# 未定稿 / NOTHING FINAL · Chrome Web Store V7 — Visual Direction

这一版以“静默轨道”为视觉母题：新的开放圆环不是封闭的徽章，而是一段仍在发生的思考；右上方的珊瑚色小点既像进入轨道的念头，也像对话尚未落下的句点。画面只使用墨黑、象牙白与少量珊瑚橙，让 Logo 成为唯一明确的色彩信号，不再与界面争夺注意力。

商店截图首先是产品证据。每一张图都必须来自当前真实界面，并让界面本身占据画面的主要面积；外部编排只负责建立秩序、说明场景和承接品牌，不用抽象装饰遮盖功能。窗口边框、细线与留白延续「未定稿」的手稿感，但密度要比产品内部更低。

整体采用编辑式、安静而克制的构图。标题短而有人味，避免堆叠功能词；说明文字控制在一行。中文以宋体气质承接阅读感，英文用高对比衬线体建立出版物感，界面标签仍保留系统无衬线体，形成“内容—工具”的清晰层级。

五张预览图组成一条完整路径：在新标签页偶遇一句话，选择哲学、经济、心理或自己的知识，进入深读，沿思想网络看见关系，最后把值得留下的内容保存或分享。用户不需要阅读一套说明书，只需顺着图序就能理解「未定稿」如何融入每天的浏览。

宣传图块采用“品牌 + 真实界面”的双主体，而不是纯抽象海报。小图块只保留 Logo、当前语言的品牌名与一句定位；顶部图块则用大幅留白托住当前界面片段。所有截图与宣传图导出为 sRGB、无透明通道 PNG；只有 128×128 商店图标保留透明通道，并严格使用提供的新 Logo 矢量源。
