## 短介绍

每次打开新标签页，遇见一则思想。阅读五个思想集的双语命题、解读与思想脉络；无账号、无追踪、无需权限。

## 详细介绍

以下文本可直接粘贴到商店详情页：

```text
一页，一种思想。

AGORA 把 Chrome 新标签页变成一个安静的思想入口。每次打开新页，随机遇见一则可继续展开的研读卡：先读原文或双语命题，再进入核心解读、作品与论证语境、辨析边界，以及思想来处、同题异答和后续回响。

五个思想集

· 西方哲学
· 中国哲学
· 毛选
· 科学思想
· 印度哲学

也可以选择“跨集随机”，在不同传统之间漫游。

不只是一面金句墙

AGORA 收录 1000+ 张研读卡，并为部分内容配有数百张原创极简线稿。卡片会尽量标明人物、作品、出处线索和文本性质；直接引文、译写与研读性转述不会混为一谈。

为日常阅读而设计

· 简体中文、繁体中文与 English，可选中文下同时显示英文
· 核心解读、语境、边界、思想来处、异答与回响
· 收藏、最近阅读、屏蔽、搜索和筛选
· 三种手稿主题与克制的环境动效
· 键盘、鼠标与触控操作
· 生成桌面或移动版分享图，保存、复制或系统分享

安静，也尊重隐私

无需账号，没有广告和追踪，不请求 Chrome 权限；偏好、收藏、最近阅读与屏蔽内容仅保存在本机，并可离线使用。

AGORA 不用一句话替代原典，只想给你一个再读深一层的理由。
```

## 五张商店截图文案

Chrome 商店最多上传五张截图。V2 不再用“首页、详情、设置”的功能清单顺序，而是按“遇见—漫游—读深—留下—带走”讲完整产品故事。截图必须以真实产品界面为主体，生成图只作为概念底材或弱背景。

### 01｜遇见

- 文件：`upload/zh-CN/screenshot-01-discover-1280x800.png`
- 标题：**每一次新页，遇见一种思想。**
- 副文：一页，一种思想。
- 真实界面：全屏新标签页、一则中英双语思想卡、作者与作品信息。
- 生成底材：一个极淡的“开放门洞 / 光线进入”线稿，只占边缘，不遮挡句子。

### 02｜漫游

- 文件：`upload/zh-CN/screenshot-02-collections-1280x800.png`
- 标题：**五个思想集，一次跨传统的漫游。**
- 副文：西方哲学 · 中国哲学 · 毛选 · 科学思想 · 印度哲学
- 真实界面：当前内容库选择器，并显示“跨集随机”。
- 生成底材：五条路径或五扇不完整门洞汇向同一片开放空间；不画人物肖像或政治符号。

### 03｜读深

- 文件：`upload/zh-CN/screenshot-03-read-deeper-1280x800.png`
- 标题：**不是金句，是思想的来路与去处。**
- 副文：原文与译写、核心解读、语境边界、同题异答与后续回响
- 真实界面：选择内容丰富且已有配图的详情弹窗，清晰展示解读结构和思想关系。
- 生成底材：使用该研读卡对应的原创线稿，以低对比度进入弹窗背景或叙事侧边。

### 04｜留下

- 文件：`upload/zh-CN/screenshot-04-library-1280x800.png`
- 标题：**留下想重读的，屏蔽不想再见的。**
- 副文：收藏、最近阅读与已屏蔽内容，都只留在本地
- 真实界面：思想册中的收藏、最近阅读、已屏蔽、搜索或筛选状态。
- 生成底材：书签、索引卡或档案页的稀疏线稿，不做写实书架。

### 05｜带走

- 文件：`upload/zh-CN/screenshot-05-share-1280x800.png`
- 标题：**把一句思想，带到下一次对话里。**
- 副文：生成桌面或移动版分享图；保存图片、复制文本或系统分享
- 真实界面：分享工作台、桌面/移动样式切换，以及三个真实操作按钮。
- 隐私行：无账号 · 无追踪 · 无需权限 · 离线可用
- 生成底材：一张纸页向另一片空间延伸的抽象线稿，避免平台 Logo 拼贴。

## 版本更新说明

“素材 V2”不是扩展版本号。下面提供两版 Chrome Web Store 更新说明，发布时只选择与实际版本差异吻合的一版。

### 从 `0.2.2` 或更早版本升级时

```text
AGORA 现已扩展为五个思想集：西方哲学、中国哲学、毛选、科学思想与印度哲学。中国哲学内容得到系统扩充，并新增科学思想、印度哲学以及更完整的观点来源和思想脉络。跨集随机现在会先在五个内容库之间等概率选择；详情内容改为按需加载，首次打开更轻。我们也为更多研读卡补充了原创极简线稿，并继续改善出处、文本性质与研究边界的标注。
```

### 从 `0.2.3` 升级到下一版本时

```text
本次更新为更多研读卡补充原创极简线稿，并优化插画在详情与分享场景中的呈现；同时改善详情弹窗的阅读密度、主题一致性和思想关系展示。内容仍保存在本机，无账号、无追踪，也不请求 Chrome 权限。
```

发布前请删除尚未进入待上传构建的功能描述，不要仅因为素材已经制作就提前声明功能已经上线。
